# 📚 Apyclipy User Guide

## 🎯 Quick Start

### First Time Setup

1. **Launch the Application**: Open Apyclipy in your browser or desktop app.
2. **Initial Setup**: Configure your AI model API key in Settings -> AI Models.
3. **Start Clipping**: Ingest a video by URL or drag-and-drop a video file.

### Core Workflow

```
Input Video -> Speech Transcription -> AI Highlight Analysis -> Smart Video Cutting -> Export & Publish
```

## 📁 Project Management

### Creating a Project

1. On the home screen, paste a video URL or drop a local video file (`.mp4`, `.mov`, `.mkv`).
2. Optional: Supply a `.srt` subtitle file if you want to skip audio transcription.
3. Choose your target platforms (Shorts, TikTok, Reels, YouTube).
4. Configure advanced preferences if needed:
   - **Selective Segment Crop**: Specify a time range (e.g. `00:00:00` - `00:15:00`).
   - **Target Clip Count**: Set output volume (Auto 4-6, or custom 1-10 clips).
   - **Download Quality**: Select 720p HD (High Speed) or 1080p Full HD.
5. Click **Generate Videos**.

### Monitoring Progress

- **Download & Transcribe**: Video media is downloaded and processed for subtitles.
- **AI Analysis & Scoring**: Speech and visual content are scored for viral potential and narrative coherence.
- **Auto Editing & Video Render**: Highlights are cut, formatted for selected aspect ratios, and rendered with dynamic subtitles.

## 🎬 Clip Editing & Export

- **Preview Clips**: Watch generated clips directly in the studio with synchronized subtitles.
- **Export Kits**: Download finished videos, covers, descriptions, and hashtag recommendations.
- **Clean Output**: Videos are exported cleanly with zero appended watermarks or outro logos.
