# Apyclipy MCPB

Lightweight MCP Bundle for Model Context Protocol integration.

The host launch command is `uv run --directory <this_dir> src/server.py`. Requires `uv`, `ffmpeg`, and `ffprobe` in `PATH`. Python 3.10+ is managed via UV.

`AUTOCLIP_API_KEY` is optional. Leave blank if desktop or environment keys are already configured.
