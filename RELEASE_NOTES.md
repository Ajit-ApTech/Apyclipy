# Apyclipy Release Notes

## Version 2.0.0 (Enhanced Edition)

### ✨ What's New

1. **Rebranding to Apyclipy**:
   - Redesigned visual identity and modern Electric Obsidian theme.
   - Clean UI without third-party repository branding or legacy ties.

2. **100% English Localization**:
   - Complete localization across all frontend pages, progress monitors, readiness lines, error handling, and settings panels.
   - Live translation bridge for real-time model streaming status.

3. **Selective Time Segment Crop**:
   - Added selective segment extraction (`00:00:00` – `00:15:00`) for processing 1–4 hour long videos in minutes without full-length ingestion delays.

4. **Target Clip Volume Controls**:
   - Customize exact output count (Auto 4–6 clips based on content density, or specify 1 to 10 clips).

5. **Download & Processing Quality Selector**:
   - Choose between **720p HD** (3–4x faster downloads) and **1080p Full HD**.

6. **Watermark-Free Video Exports**:
   - Removed all appended ending logos and outro watermarks. Video clips render cleanly from start to finish.

7. **Interactive Live Progress Feedback**:
   - Live 3-stage progress visualization (*Download & Transcribe*, *AI Analysis & Scoring*, *Auto Editing & Video Render*).
   - Real-time pulse indicator, stream token counts, and elapsed / remaining ETA displays.
